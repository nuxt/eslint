TypeScript version of [`@nuxtjs/eslint-config`](/modules/eslint/legacy-eslint-config), for Nuxt 2.

::tip
This package is for Nuxt 2. For Nuxt 3 projects, use [`@nuxt/eslint`](/modules/eslint) instead.
::

::warning
This package is in maintainance mode and no longer have active developments.
::

::note
The package is published on npm as [`@nuxtjs/eslint-config-typescript`](https://www.npmjs.com/package/@nuxtjs/eslint-config-typescript).
::

### Usage

Refer to [this page](/modules/eslint/legacy-eslint-config#typescript) for the usage.
