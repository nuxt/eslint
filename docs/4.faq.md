This project is composed of multiple packages for different level of ESLint integration.

### What to use?

For new projects, we highly recommend using the [ESLint Module](/modules/eslint) which provides a project-aware ESLint flat config generation and is more future-proof.

If you still use the legacy `.eslintrc` format, `@nuxt/eslint-config` v0.x is the last version that provides a legacy config. Since v1.0, the [ESLint Config](/modules/eslint/config) package only supports flat config, so we recommend you to migrate to the flat config format if possible.

If you are maintaining your custom ESLint config and want a low-level setup, you can use the [ESLint Plugin](/modules/eslint/plugin) package directly to enable some Nuxt-specific rules in your config.

### Package Disambiguation

Due to the historical reasons, we have quite a few packages for different ESLint integrations.
